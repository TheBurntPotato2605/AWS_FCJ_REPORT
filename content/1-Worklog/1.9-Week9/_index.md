### Week 9 Goals:

* Understand and implement Cross-Domain Authentication with Amazon Cognito.
* Learn how to monitor networks using VPC Flow Logs and analyze network traffic.
* Explore how to protect sensitive data with Amazon Macie.

### Tasks to be implemented this week:
| Day | Task                                                                                                                                                                                                 | Start Date   | End Date         | Reference Material                       |
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------|------------------|-------------------------------------------|
| 2   | - Get familiar with Amazon Cognito. <br> - Learn concepts: User Pool, Identity Pool, Federation, Hosted UI.                                                  | 03/11/2025   | 03/11/2025       | [AWS Study Group](https://cloudjourney.awsstudygroup.com/) |
| 3   | - Configure Cross-Domain Authentication. <br> - Integrate Cognito with web applications. <br> - Test login from multiple domains.                           | 04/11/2025   | 04/11/2025       | [AWS Study Group](https://cloudjourney.awsstudygroup.com/) |
| 4   | - Get familiar with VPC Flow Logs. <br> - Learn how to log, store, and analyze network logs.                                                                | 05/11/2025   | 05/11/2025       | [AWS Study Group](https://cloudjourney.awsstudygroup.com/) |
| 5   | - Practice creating VPC Flow Logs. <br> - Send logs to CloudWatch. <br> - Query logs to analyze network traffic.                                            | 06/11/2025   | 06/11/2025       | [AWS Study Group](https://cloudjourney.awsstudygroup.com/) |
| 6   | - Get familiar with Amazon Macie. <br> - Learn how to detect sensitive data in S3. <br> - View reports and alerts from Macie.                               | 07/11/2025   | 07/11/2025       | [AWS Study Group](https://cloudjourney.awsstudygroup.com/) |

### Week 9 Achievements:

* Understand how Amazon Cognito works and its related components.
* Learn how to configure user authentication across multiple domains.
* Successfully integrate Cognito into web applications and test login.
* Create and configure VPC Flow Logs to monitor networks.
* Analyze network logs using CloudWatch Logs to detect anomalies.
* Configure Amazon Macie to scan data in S3 and detect sensitive information.
