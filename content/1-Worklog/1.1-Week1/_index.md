### Week 1 Achievements:

* Grasp basic knowledge about AWS and its services.
* Get familiar with AWS Management Console and learn how to find, access, and use services via the web interface.
* Successfully create and configure an AWS Free Tier account.
* Set up MFA for the root account using Google Authenticator.
* Learn how to create a group and IAM user to manage AWS resources.
* Understand and learn how to manage costs when using AWS services with AWS Budget.
