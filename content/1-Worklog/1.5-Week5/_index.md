### Week 5 Goals:

* Master organizing AWS resources using Tags and Resource Groups.
* Understand access control mechanisms with IAM and tag types.
* Efficiently manage systems using AWS Systems Manager.
* Set up identity federation with AWS Single Sign-On.
* Manage permissions with IAM Permission Boundaries.
* Apply IAM policies and conditions for detailed access control.
