### Week 4 Goals:

* Learn and deploy several open-source applications on Amazon Lightsail and configure Lightsail resources.
* Practice running applications on Lightsail Container.
* Get familiar with the Amazon Route 53 service.
* Learn how to optimize EC2 costs.
* Learn how to monitor and track AWS resources with Grafana.

### Week 4 Achievements:

* Get familiar with Amazon Lightsail, successfully deploy several applications on Lightsail, and configure application security.
* Successfully create Container Service and deploy container images on Amazon Lightsail.
* Understand how to set up hybrid DNS in on-premise and AWS systems.
* Learn how to automate and reduce costs when using EC2 with Lambda.
* Practice monitoring with Grafana:
  * Create dashboards, visualize metrics based on data.
  * Track the activity of applications and systems.
