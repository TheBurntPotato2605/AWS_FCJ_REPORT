### Week 7 Goals:

* Get familiar with Infrastructure as Code (IaC) using AWS CloudFormation.
* Understand and apply Right-Sizing to optimize EC2 costs.
* Practice Scaling Applications with EC2 Auto Scaling.
* Deploy WordPress on Amazon EC2.

### Week 7 Achievements:

* Begin to get familiar with the concept of **Infrastructure as Code (IaC)** and how to use CloudFormation.
* Start learning about **Right-Sizing** and how to use Cost Explorer to analyze EC2 costs.
* Get familiar with the concept of **EC2 Auto Scaling** and try creating an Auto Scaling Group at a basic level.
* Try deploying **WordPress on EC2** to understand the initial setup and configuration process.
