### Week 6 Goals:

* Begin exploring basic security concepts in AWS: IAM, Security Hub, VPC Endpoint, WAF, KMS.

### Tasks to be implemented this week:
| Day | Task                                                                                                                                                                                                 | Start Date   | End Date         | Reference Material                       |
|-----|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------|------------------|-------------------------------------------|
| 2   | - Learn an overview of access control with IAM Policies and Conditions. <br> - Get familiar with writing simple policies and adding basic conditions.        | 13/10/2025   | 13/10/2025       | [AWS Study Group](https://cloudjourney.awsstudygroup.com/) |
| 3   | - Learn the basics of security compliance with AWS Security Hub. <br> - Understand how to enable and view aggregated security alerts from multiple services. | 14/10/2025   | 14/10/2025       | [AWS Study Group](https://cloudjourney.awsstudygroup.com/) |
| 4   | - Get familiar with the concept of private access to S3 using VPC Endpoints. <br> - **Practice:** Create a VPC Endpoint and test accessing S3 from the internal network. | 15/10/2025   | 15/10/2025       | [AWS Study Group](https://cloudjourney.awsstudygroup.com/) |
| 5   | - Learn the basics of application protection with AWS WAF. <br> - Create a simple Web ACL and test blocking some common request types.                       | 16/10/2025   | 16/10/2025       | [AWS Study Group](https://cloudjourney.awsstudygroup.com/) |
| 6   | - Get familiar with encryption using AWS Key Management Service (KMS). <br> - Create encryption keys and try applying them with S3 or RDS.                   | 17/10/2025   | 17/10/2025       | [AWS Study Group](https://cloudjourney.awsstudygroup.com/) |

### Week 6 Achievements:

* Understand how to write basic IAM policies and add simple conditions.
* Learn how to enable Security Hub and view aggregated security alerts.
* Understand how to set up private access to S3 via VPC Endpoint.
* Create a simple Web ACL with AWS WAF to block some request types.
* Get familiar with creating and using encryption keys with AWS KMS at a basic level.
