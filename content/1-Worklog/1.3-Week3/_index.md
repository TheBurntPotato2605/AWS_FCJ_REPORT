### Week 3 Goals:

* Learn how to host a static website using S3.
* Get familiar with EC2 and its basic features.
* Understand how to deploy and manage relational databases on AWS.
* Install and use AWS CLI to interact with AWS services.
* Monitor and manage system performance with CloudWatch.

### Week 3 Achievements:

* Learn how to host and configure static websites using S3.
* Understand Amazon EC2 - AWS's core virtual server service, its operation, and its important components:
  * AMI.
  * Keypair.
  * Instance.
* Grasp basic knowledge about databases with RDS:
  * Create RDS database instances.
  * How to deploy, back up, and restore applications on RDS.
